## Preview locally

Both CV versions are self-contained HTML documents. Run a simple local server:

```sh
python3 -m http.server 8000
```

Then open:

- <http://localhost:8000> for the one-page CV
- <http://localhost:8000/detailed/> for the detailed CV

## Create a PDF

Use the **Print / Save as PDF** button in either version, or print the relevant
page from a browser with:

- paper size: A4
- scale: 100%
- margins: none
- background graphics: enabled

The print stylesheets produce a one-page or two-page A4 document, respectively,
with selectable text and working links.
