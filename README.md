## Preview locally

The CV is a self-contained HTML document. Open `index.html` in a browser or run
a simple local server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Create a PDF

Use the **Print / Save as PDF** button in the web version, or print
`index.html` from a browser with:

- paper size: A4
- scale: 100%
- margins: none
- background graphics: enabled

The print stylesheet produces a two-page A4 document with selectable text and
working links.
